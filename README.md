A one-page newspaper infographic summing up the world news of Saturday 21 November 2026: Russian missiles landing in Poland and the "intentional provocation" row, the Berlin summit of the "coalition of the willing", the deepening AI sell-off as Anthropic slides, Claude's part in a proof of the Riemann Hypothesis, and the UK–EU reset — plus a first resettlement plan for Rohingya refugees. Drawn by a program from the day's real reporting.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image itself is rendered by `tools/generate.py` (Pillow, from the day's
reporting); `main.py` only copies the finished `entry.png` to the output
directory, so both runs write the same bytes.
